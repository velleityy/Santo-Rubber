SANTO RUBBER GROUP — WEBSITE FILES

GET STARTED
Unzip this folder and open index.html in your browser.
No installation or build step is required.

FILES
index.html — page content, navigation, contact form and brochure links
styles.css — colors, typography, layout and mobile styling
app.js — product data, company profiles, factory profiles and interactions
assets/ — product and factory photographs plus downloadable brochures
SOURCE_NOTES.md — content sources and implementation notes

EDITING
Edit index.html for general page text and contact details.
Edit app.js for product, company and facility descriptions.
Edit styles.css to change the appearance.
Keep assets in the same folder structure so images and downloads work.

HOSTING
Upload index.html, styles.css, app.js and the complete assets folder to a static website host.
Use HTTPS for the Copy inquiry text feature. A manual text-copy fallback is included.

INQUIRIES
The form prepares messages in the visitor's email app or WhatsApp.
It does not store submissions or send messages automatically.
The visitor must review and send the message in their chosen app.

The downloadable package does not change or replace the privately hosted Site.
